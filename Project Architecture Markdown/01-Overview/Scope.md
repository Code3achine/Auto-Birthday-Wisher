# Scope

## ✅ In Scope
- Add, edit, delete birthday records
- View birthday list
- Daily birthday check
- Automatic WhatsApp message
- Custom birthday message
- Message logging

## ❌ Out of Scope
- SMS integration
- Email integration
- Social media posting
- Gift ordering
- Cloud synchronization
