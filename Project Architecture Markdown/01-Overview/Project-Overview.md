# Project Overview

**Title:** Birthday Reminder and Automatic WhatsApp Wish System Using Selenium

## Purpose
Develop a desktop application that automatically checks birthdays from stored records and sends personalized birthday wishes through WhatsApp Web using Selenium automation.

## Summary
The system stores friends' birthday information in a local database or CSV file. Every day, the application checks the current date. If a birthday matches, the system opens WhatsApp Web, searches for the contact, sends a predefined birthday message automatically, and records the successful delivery in a log.
