# Glossary / Technical Skills Required

- Python
- Selenium WebDriver
- Clipboard Automation (pyperclip)
- XPath/CSS Selectors
- SQLite or CSV
- File Handling
- OOP
- Exception Handling
- Windows Task Scheduler
- Debugging

## Conclusion
The system automates birthday detection and WhatsApp birthday wishes using Selenium and WhatsApp Web — suitable as an academic project demonstrating automation, scheduling, database management, and software engineering.
